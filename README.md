## 🧭 About This Repository

This repository is a **hands-on Data Analyst learning and practice workspace**.

It contains practical exercises and projects focused on the complete analytics workflow:

```text
📥 Collect Data
      ↓
🧹 Clean Data
      ↓
🔍 Explore Data
      ↓
📊 Analyze Data
      ↓
📈 Visualize
      ↓
🧮 Calculate KPIs
      ↓
🧠 Generate Insights
      ↓
💡 Recommend Business Actions
```

The goal is not only to write code, but to develop the ability to turn raw data into **clear, actionable business insights**.

# 💼 Business Analytics

A Data Analyst should go beyond:

> **"What is the number?"**

and answer:

> **"Why did it happen?"**

> **"What changed?"**

> **"Which segment caused the change?"**

> **"What should the business do next?"**

Typical business problems include:

- 📉 Sales decline
- 👥 Customer churn
- 🛒 E-commerce conversion
- 📢 Marketing campaign analysis
- 📦 Product performance
- 💳 Revenue analysis
- 📱 Telecom analytics
- 👨‍💼 Employee attrition
- 🚚 Delivery performance
- 💰 Customer value

# 📌 Key KPIs

Practice includes common Data Analyst KPIs such as:

| KPI | Example |
|---|---|
| 💰 Revenue | `Quantity × Price` |
| 🛒 AOV | `Revenue / Orders` |
| 🎯 Conversion Rate | `Conversions / Visitors × 100` |
| 📈 Growth | `Current vs Previous` |
| 👥 Churn Rate | `Churned Customers / Total Customers` |
| 🔄 Retention | `Returning Customers / Previous Customers` |
| 💵 ARPU | `Revenue / Customers` |
| 🏆 Customer Revenue | `SUM(Revenue) by Customer` |

# ⚙️ Getting Started

## 1️⃣ Clone the repository

```bash
git clone https://github.com/Chandrabhawan/Data_Analyst.git
cd Data_Analyst
```

## 2️⃣ Create a virtual environment

### macOS / Linux

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### Windows

```bash
python -m venv .venv
.venv\Scripts\activate
```

## 3️⃣ Install the main Python libraries

```bash
pip install pandas numpy matplotlib seaborn jupyter
```

## 4️⃣ Start Jupyter

```bash
jupyter notebook
```

or:

```bash
jupyter lab
```
